# EWMA API Documentation

Документация публичного интерфейса приложения **EWMA ARL Calculator**.

> **Важно**: это консольная C++-программа, а не HTTP-сервис. Понятие «endpoints» здесь отражено тремя слоями:
> 1. **CLI-интерфейс** — аргументы, с которыми запускается `bin/ewma`
> 2. **Конфигурация** — JSON-файл с параметрами запуска
> 3. **Файловый вывод** — CSV-файлы результатов и журналы
>
> Дополнительно описана библиотечная часть (заголовочные файлы) — она доступна для повторного использования в C++.

## 1. CLI-интерфейс

Общий синтаксис:

```
ewma [options]
```

### Таблица опций

| Опция | Тип | Значение по умолчанию | Описание |
|-------|-----|----------------------|----------|
| `--config <file>` | строка | — | Загрузить конфигурацию из JSON-файла |
| `--chart <SN\|SR>` | строка | `SN` | Тип контрольной карты: знаковая (SN) или знаково-ранговая (SR); регистр не важен, неизвестное значение → предупреждение и `SN` |
| `--simulations <N>` | int | `5000` | Число прогонов Монте-Карло на пару `(lambda, L)` |
| `--n <N>` | int | `14` | Размер подгруппы (выборки) |
| `--max_iter <N>` | int | `5000` | Максимальная длина серии на прогон |
| `--target_ARL <value>` | double | `370.0` | Целевой ARL |
| `--cores <N>` | int | авто | Число ядер CPU для OpenMP (≤0 = все доступные) |
| `--tolerance <value>` | double | `-1.0` | Ранняя остановка, если отклонение от цели ≤ значению (`-1` = выкл.) |
| `--update_interval <N>` | int | `5` | Обновление прогресс-бара каждые N комбинаций |
| `--lambda_start <s> <e> [step]` | 2–3 числа | `0.05 0.20 0.05` | Диапазон значений `lambda` (шаг по умолчанию `0.05`) |
| `--L_start <s> <e> [step]` | 2–3 числа | `2.4 3.0 0.05` | Диапазон значений `L` (шаг по умолчанию `0.05`) |
| `--resume` | флаг | выкл. | Продолжить расчёт с контрольной точки |
| `--no-resume` | флаг | по умолч. | Начать заново (удаляет temp/checkpoint) |
| `--help`, `-h` | флаг | — | Показать справку и выйти |

### Семантика

- **Приоритет**: если передан `--config`, загружаются его значения; последующие опции CLI перезаписывают отдельные поля.
- **Сетка значений**: если `lambda_values`/`L_values` не заданы (ни конфигом, ни CLI), применяется диапазон `lambda` 0.05 … 0.20 (шаг 0.05, 4 значения) и `L` 2.4 … 3.0 (шаг 0.05, 13 значений). Диапазон подобран для ARL_IC ≈ 500; выбранный `lambda` зависит от размера сдвига (0.05 — малый, 0.10 — умеренный, 0.20 — большой).
- **`n_cores`**: значение `≤ 0` включает автоопределение (`std::thread::hardware_concurrency()`, минимум 4 при сбое).
- **`--resume`**: продолжает расчёт, читая `arl_calculation_temp.csv` и `arl_checkpoint.txt`. Если temp-файла нет — программа предупреждает и стартует заново.
- **Ранняя остановка**: срабатывает, как только найденная пара даёт `|ARL − target_ARL| ≤ tolerance`; найденное решение сразу сохраняется.

## 2. Конфигурация (JSON)

Файл: `config/default_config.json`. Формат — JSON-объект.

### Схема

| Ключ | Тип | По умолчанию | Обязателен | Описание |
|------|-----|--------------|------------|----------|
| `simulations` | int | `5000` | нет | Прогонов Монте-Карло на пару |
| `n` | int | `14` | нет | Размер подгруппы |
| `max_iter` | int | `5000` | нет | Обрыв серии при отсутствии сигнала |
| `target_ARL` | double | `370.0` | нет | Целевой ARL |
| `n_cores` | int | `0` | нет | Ядра CPU (≤0 = авто) |
| `checkpoint_interval` | int | `5` | нет | Сохранять контрольную точку каждые N комбинаций |
| `top_n` | int | `10` | нет | Сколько лучших пар сохранять/выводить |
| `tolerance` | double | `-1.0` | нет | Допуск ранней остановки (−1 = выкл.) |
| `update_interval` | int | `5` | нет | Обновление прогресс-бара каждые N комбинаций |
| `chart_type` | string | `SN` | нет | Тип карты: `SN` (знаковая) или `SR` (знаково-ранговая) |
| `lambda_values` | array<double> | см. CLI | нет | Сетка значений `lambda` (константа сглаживания) |
| `L_values` | array<double> | см. CLI | нет | Сетка значений `L` (множитель предела) |
| `temp_file` | строка | `arl_calculation_temp.csv` | нет | Временный CSV |
| `checkpoint_file` | строка | `arl_checkpoint.txt` | нет | Файл контрольной точки |
| `final_file` | строка | `arl_results_final.csv` | нет | Финальный CSV |
| `best_file` | строка | `best_arl_pairs.csv` | нет | CSV лучших пар |
| `log_file` | строка | `arl_calculation.log` | нет | Журнал |
| `error_file` | строка | `errors.log` | нет | Журнал ошибок |
| `resume` | bool | `false` | нет | Продолжить с контрольной точки |

### Пример

```json
{
    "simulations": 5000,
    "n": 14,
    "lambda_values": [0.05, 0.10, 0.20],
    "L_values": [2.5, 2.7, 2.9],
    "target_ARL": 370.0
}
```

### Правила валидации

- Неизвестные ключи игнорируются.
- Отсутствующие ключи получают значения по умолчанию.
- Недоступный `n_cores` заменяется числом ядер CPU.
- Некорректный JSON печатает `Error loading config: <причина>` в stderr и использует значения по умолчанию.
- Пустые `lambda_values`/`L_values` заменяются диапазонами `0.05 … 0.20` (шаг 0.05) и `2.4 … 3.0` (шаг 0.05).

## 3. Схемы данных (CSV)

Все файлы создаются в рабочей директории, значения — с 6 знаками после запятой.

### `arl_calculation_temp.csv` и `arl_results_final.csv`

Рабочий/итоговый результат по всем парам `(lambda, L)`.

```
lambda,L,ARL
0.100000,2.700000,500.200000
0.100000,2.800000,534.100000
```

| Колонка | Тип | Описание |
|---------|-----|----------|
| `lambda` | double | Константа сглаживания EWMA |
| `L` | double | Множитель контрольного предела |
| `ARL` | double | Средняя длина серии (прогоны Монте-Карло) |

### `best_arl_pairs.csv`

Топ `top_n` пар с минимальным отклонением ARL от цели.

```
lambda,L,ARL,Deviation
0.100000,2.700000,500.200000,0.200000
```

| Колонка | Тип | Описание |
|---------|-----|----------|
| `lambda` | double | Константа сглаживания |
| `L` | double | Множитель контрольного предела |
| `ARL` | double | Рассчитанный ARL |
| `Deviation` | double | `abs(ARL − target_ARL)` |

### `arl_checkpoint.txt`

Контрольная точка — последняя обработанная комбинация.

```
0.100000,2.700000
```

### `arl_calculation.log`

Построчный журнал с временными метками:

```
[Fri Sep  4 23:52:20 2026] Total combinations: 52
[Fri Sep  4 23:52:20 2026] Remaining: 52
```

### `errors.log`

Ошибки по конкретным парам:

```
[<timestamp>] lambda=0.100000, L=2.700000, error=<сообщение>
```

## 4. C++ API

Пространство имён `ewma`. Сборка CLI использует: `Config`, `Calculator`, `Simulator`, `Utils`, `ProgressBar`. Класс `ResultManager` реализован, но **не входит в сборку** (отсутствует в `Makefile`).

### `Config` (include/Config.hpp)

Структура конфигурации (поля совпадают с JSON-схемой).

| Метод | Сигнатура | Описание |
|-------|-----------|----------|
| `loadFromFile` | `static Config loadFromFile(const std::string&)` | Загрузка из JSON |
| `loadFromArgs` | `static Config loadFromArgs(int, char**)` | Парсинг CLI-аргументов |
| `saveToFile` | `void saveToFile(const std::string&) const` | Сериализация в JSON |
| `print` | `void print() const` | Вывод конфигурации в stdout |

### `Calculator` (include/Calculator.hpp)

Оркестратор перебора сетки, чекпоинтов, сохранения результатов.

| Метод | Сигнатура | Описание |
|-------|-----------|----------|
| `run` | `void run(const Config&)` | Запуск полного перебора |
| `resume` | `void resume(const Config&)` | Продолжение расчёта |

### `Simulator` (include/Simulator.hpp)

Монте-Карло симуляция EWMA-карты. Тип карты задаётся перечислением `ewma::ChartType { SN, SR }` (значение по умолчанию — `ChartType::SN`).

| Метод | Сигнатура | Описание |
|-------|-----------|----------|
| `simulateBatch` | `double simulateBatch(lambda, L, simCount, n, maxIter, seed, chart)` | ARL одной партии (последовательно) |
| `calculateARLParallel` | `double calculateARLParallel(lambda, L, simCount, n, maxIter, numThreads, chart)` | ARL с параллельными прогонами |
| `simulateBatchWithDistribution` | `tuple<double, vector<int>, vector<double>>` | ARL + длины серий + статистика |
| `calculateARLParallelWithDistribution` | то же | Параллельная версия с распределением |

### `Utils` (include/Utils.hpp)

| Метод | Описание |
|-------|----------|
| `RandomGenerator::getInstance()` | Глобальный ГПСЧ (синглтон) |
| `fileExists / readFile / writeFile / deleteFile` | Работа с файлами |
| `split / trim` | Строковые операции |
| `formatTime(seconds)` | Секунды → `HH:MM:SS` |
| `roundTo(value, decimals)` | Округление |
| `isClose(a, b, eps)` | Сравнение с допуском |
| `calculateMean / calculateStdDev / calculatePercentile / calculateHistogram` | Описательная статистика |

### `ProgressBar` (include/ProgressBar.hpp)

| Метод | Описание |
|-------|----------|
| `update(current, message, arl)` | Перерисовать прогресс |
| `increment(step, message, arl)` | Шаг вперёд и перерисовка |
| `finish(message)` | Завершить |
| `setBestResult(lambda, L, arl, target)` | Показать текущий лучший результат |
| `setEarlyStop(stopped)` | Отметить раннюю остановку |

## 5. Обработка ошибок и коды

### Коды завершения

| Код | Значение | Когда |
|-----|----------|-------|
| `0` | Успех | Всегда (при обычном завершении) |
| `-` | **Не реализовано** | Ненулевых кодов в проекте нет; ошибки не прерывают процесс (`[TODO]` в Roadmap) |

### Журналы ошибок

| Место | Назначение |
|-------|------------|
| stderr | `Warning: Config file not found: <file>`; `Error loading config: <причина>`; `Error: Cannot open file for writing: <file>` |
| `errors.log` | Исключения при расчёте конкретной пары `(lambda, L)`; расчёт продолжается со следующей парой |
| `arl_calculation.log` | Служебные события (старт, прогресс, ранняя остановка) |

### Критические сценарии

| Сценарий | Поведение |
|----------|-----------|
| Конфиг-файл не найден | Предупреждение в stderr, используются значения по умолчанию |
| Некорректный JSON | `Error loading config`, значения по умолчанию |
| `--resume` без temp-файла | Предупреждение, запуск с нуля |
| Не открывается temp-файл | Событие `ERROR: Cannot open temp file for writing` в лог, программа завершается |
| Исключение в одной паре | Запись в `errors.log`, переход к следующей паре |
| Нет результатов | `No results to save` в журнал |

## 6. Примеры запросов и ответов

### Пример 1. Справка

Запрос:

```bash
./bin/ewma --help
```

Ответ (фрагмент):

```
Usage: ewma [options]
Options:
  --config <file>        Load config from JSON file
  --simulations <N>      Number of simulations per pair
  ...
```

Код завершения: `0`.

### Пример 2. Запуск с загрузкой конфигурации

Запрос:

```bash
./bin/ewma --config config/default_config.json
```

Ответ в stdout:

```
=== EWMA ARL Calculator ===
Version 1.0.0

Configuration:
  simulations: 5000
  n: 14
  max_iter: 5000
  target_ARL: 370.000000
  ...
Fresh start mode: starting new calculation

Progress: |####----------------------------------------------|  10.0%  8/52  Elapsed: 00:00:12  ETA: 00:01:48  [lambda=0.10, L=2.7, ARL: 500.2] Best: lambda=0.100, L=2.700, ARL=500.2 (dev=130.2)
```

Выходные файлы: `arl_calculation_temp.csv`, `arl_results_final.csv`, `best_arl_pairs.csv`, `arl_calculation.log`.

### Пример 3. Поиск по диапазонам с ранней остановкой

Запрос:

```bash
./bin/ewma --lambda_start 0.05 0.20 0.05 --L_start 2.4 3.0 0.1 --simulations 2000 --tolerance 0.5
```

Ожидаемый результат: если пара даёт `|ARL − 370| ≤ 0.5`, расчёт останавливается, в stdout выводится:

```
=======================================================================
BEST PAIR (lambda, L):
  lambda = 0.100000
  L = 2.700000
  ARL = 370.400000 (deviation: 0.400000)
```

### Пример 4. Продолжение прерванного расчёта

Запрос:

```bash
./bin/ewma --resume
```

Ответ: программа читает `arl_checkpoint.txt`, загружает завершённые пары из temp-файла и продолжает с последней обработанной комбинации.
